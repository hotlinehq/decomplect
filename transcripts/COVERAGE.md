# Transcript coverage

Source: every transcript in [matthiasn/talk-transcripts/Hickey_Rich](https://github.com/matthiasn/talk-transcripts/tree/master/Hickey_Rich)
(download with `fetch.sh`), checked against the talk list in
[tallesl/Rich-Hickey-fanclub](https://github.com/tallesl/Rich-Hickey-fanclub).
A GitHub search found no other English transcript collection (only Japanese and French translations of single talks).
Slide images from the source repo are not copied; each `.md` links to the video and slides.
